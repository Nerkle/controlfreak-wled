# SerialControl Usermod


Each release of wled is branched from the release tag. Example: `wled-0.15.0`

```
git checkout tags/v0.15.0 -b wled-0.15.0
```

Each release of controlfreak-wled is branched off the WLED release branch and start with the base wled version number. Example: `controlfreak-wled-0.15.0.1`

controlfreak-firmware versions are mapped to controlfreak-wled versions
